# 🛍️ Quick Curtains and Deco – E-commerce SPA

A modern, single-page React application for browsing and purchasing home décor products including curtains, blinds, and wallpapers. Built with a focus on responsive design, modular architecture, and smooth user experience.

## 🚀 Features

- 🧵 **Product Categories**: Ready-Made Curtains, Window Blinds, Wallpapers
- 🛒 **Cart Functionality**: Add/remove items with real-time updates
- 📱 **Responsive Design**: Optimized for mobile and desktop
- 🔄 **SPA Navigation**: Seamless page transitions using React Router
- 🧩 **Modular Components**: Reusable UI blocks for scalability
- 🎨 **Styled UI**: Clean layout with intuitive product presentation

## 🛠️ Tech Stack

- **Frontend**: React, JavaScript, CSS
- **Build Tool**: Vite
- **Routing**: React Router
- **State Management**: useReducer (for cart logic)
